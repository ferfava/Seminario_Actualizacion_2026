# TP Final Integrador — Retail Conversion Intelligence

Seminario de Actualización · Tecnicatura Superior en Ciencia de Datos e IA · IFTS N.º 18 (2026).

Proyecto en desarrollo para predecir la intención de compra en sesiones de comercio electrónico a partir del dataset **Online Shoppers Purchasing Intention** (UCI).

## Estructura prevista

- `app/frontend/`: HTML, CSS y JavaScript.
- `app/backend/`: API FastAPI.
- `app/modelo/`: modelo entrenado y exportado con joblib.
- `notebook/`: entrenamiento y evaluación del modelo.
