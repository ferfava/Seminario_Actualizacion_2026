04 / PROCESO TÉCNICO

Metodología

Etapas principales del proyecto, desde los datos originales hasta la aplicación web.

01

Datos

Dataset público UCI Online Shoppers Purchasing Intention: 12.330 sesiones y variable objetivo Revenue.

02

Preparación

Se quitaron 125 filas exactamente repetidas; se seleccionaron ocho variables y se aplicó escalado y codificación dentro del Pipeline.

03

Entrenamiento

Comparación de cuatro configuraciones con validación cruzada sobre entrenamiento. Ganó Random Forest con cinco muestras mínimas por hoja.

04

Aplicación

Modelo guardado con joblib, API desarrollada con FastAPI y frontend propio con HTML, CSS y JavaScript.

Alcance y limitaciones

El dataset no contiene identificadores únicos, por lo que algunas filas iguales podrían haber representado sesiones distintas. Las probabilidades son estimaciones del modelo, no certezas. El proyecto es académico y experimental.
